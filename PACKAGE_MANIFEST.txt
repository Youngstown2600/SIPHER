S.I.P.H.E.R. 1.0.0 r14 — FreeBSD audio compatibility + main-screen dial prefix + live audio hot-swap release

Base: r13 main-screen prefix + r12 live audio hot-swap + r11 audio lifecycle + r10 SIP-capture updates

r14 additions:
- Generic FreeBSD `snd_hda` laptop Speaker/Headphones compatibility detection; no hardcoded NIDs.
- Auto-fix only for exactly one fixed Speaker + one jack Headphones + no analog Line-out.
- Firmware Speaker association retained; Headphones moved to the same association at `seq=15`.
- Existing custom HDA hints cause a safe skip.
- Runtime HDA rebuild is validated for playback/capture and rolled back on regression.
- Successful repairs are persisted to `/boot/device.hints` after timestamped backup.
- New detector fixture tests: `tests/freebsd_audio_compat_test.sh`.

r13 additions:
- Main-screen/session dial prefix for GUI and CLI; profile prefix is startup default only.

r12 additions:
- Automatic headset/system-audio following on Linux and FreeBSD.
- Linux: PipeWire/PulseAudio sink/source/active-port watcher.
- FreeBSD: combined PulseAudio + native OSS/snd_hda watcher; tracks hw.snd.default_auto, hw.snd.default_unit, /dev/sndstat PCM inventory, and active mixer recording source.
- Live route changes use PJSIP detach -> setNoDev -> refreshDevs -> setSndDevMode -> reattach without dropping the SIP dialog.
- CLI `audio-auto on|off` and GUI automatic-follow toggle; enabled by default.
- Removed-device fallback uses PJSIP system defaults instead of stale refreshed indexes.
- Fixes CLI raw-SIP title string concatenation compile error carried from prior revisions.

Retained feature set:
- Dial prefix support and exact outbound SENT / inbound RECEIVED SIP views.
- Pre-dial SIP PCAP capture and Wireshark SIP/RTP decode helpers.
- Independent audio input/output selection and manual reopen/refresh controls.
- Queue/blast testing, RTP diagnostics, SIP ladder, reports, themes, and bounded PBX audit suite.
- Linux/FreeBSD builder, capture permissions, and verified Project-2501 ALC236 repair path.

Builder:
  ./build.sh

Supported targets:
- Linux
- FreeBSD

The builder retains automatic dependency installation, managed PJSIP 2.17 validation/bootstrap, Qt 6 dependencies, ffmpeg support, Linux capture capabilities, FreeBSD BPF/devfs permissions, audio preflight, r14's guarded generic laptop HDA compatibility pass, and the narrowly recognized ALC236 repair.
