S.I.P.H.E.R. 1.0.0 r8 — Linux / FreeBSD release

Base core: TrunkMonkey 2.0.0 Unix r20

r8 additions:
- FreeBSD pthread link fix for the CaptureManager regression target.
- Automated chained PBX/SIP audit with prioritized report and remediation.
- GUI/CLI guided audit workflow and progress feedback.
- Unified Windows/Unix PBX audit core and Windows Winsock support.
- Additional posture checks: banner/version disclosure, method surface, cleartext transport exposure, TLS legacy indicators, and correlated audit evidence.

r7 additions:
- Automatic Wireshark RTP/RTCP Decode As launch for captured calls
- GUI: OPEN LAST PCAP (AUTO RTP)
- CLI: pcap-open <id> <file>
- Targeted dynamic RTP/RTCP port mapping with rtp_udp heuristic fallback
- Standard PCAP/PCAPNG output remains unchanged and portable

Retained feature set:
- C++17/PJSUA2 SIP core and Qt GUI
- Queue/blast engine and audio injection
- SIP/RTP/combined packet capture
- RTP quality statistics, SIP ladder, call reports, registration history
- Independent audio-device selection
- Linux/FreeBSD capture permission setup
- Bounded PBX audit suite
- 26 CLI/GUI themes
- S.I.P.H.E.R. By GITSC branding

Builder:
  ./build.sh

Supported targets:
- Linux
- FreeBSD

The builder retains automatic dependency installation, managed PJSIP 2.17 validation/bootstrap, Qt 6 dependencies, ffmpeg support, Linux capture capabilities, FreeBSD BPF/devfs permissions, audio preflight, and recognized ALC236 repair.
